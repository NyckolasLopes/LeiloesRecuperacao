\# Sistema Casa de Leilões



Status do Projeto: Em desenvolvimento



Tecnologias Aplicadas:

Java (Interface Gráfica com Swing)

MySQL (Banco de Dados e JDBC)



Time de Desenvolvedores:

Nyckolas Lopes Correia Schuch



Objetivo do Software:

Sistema desktop desenvolvido para gerenciar as rotinas administrativas de uma casa de leilões, facilitando o controle de produtos, participantes e o registro de ofertas.



Funcionalidades do Sistema:

Cadastro e gestão de Produtos

Cadastro de Clientes

Registro de Lances em produtos disponíveis

Conexão e persistência de dados em banco de dados relacional
